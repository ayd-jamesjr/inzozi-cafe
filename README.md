# Inzozi Café — Café Website Concept

A responsive, front-end café website concept inspired by Kigali, Rwanda. Inzozi means “dreams” in Kinyarwanda; this portfolio project explores a welcoming café brand through editorial-style design, food and coffee imagery, and a simple mobile-friendly experience.

> **Portfolio concept only:** Inzozi Café is fictional, not an operating business. Menu items, prices, and location references are illustrative.

## Features

- Responsive landing page with a café-inspired visual identity
- Hero section, brand story, sample menu, and visit section
- Mobile navigation menu with accessible expanded-state updates
- Smooth in-page navigation
- Dynamic copyright year
- Responsive menu cards and image-led layout
- Reduced-motion support and visible keyboard focus styles

## Technology Stack

- **Structure:** HTML5
- **Styling:** CSS3, responsive media queries, CSS custom properties
- **Interactivity:** Vanilla JavaScript
- **Images:** Externally hosted Unsplash images

## Project Structure

| File | Purpose |
|---|---|
| `index.html` | Main page content and sections |
| `style.css` | Visual design, layout, and responsive styling |
| `script.js` | Mobile navigation and dynamic copyright year |

## Run Locally

No build tools, package installation, or backend server are required for this static website.

1. Clone the repository:

   ```bash
   git clone https://github.com/ayd-jamesjr/inzozi-cafe.git
   cd inzozi-cafe
   ```

2. Open `index.html` in your browser.

   Alternatively, open the folder in Visual Studio Code and use a local static development server, such as the Live Server extension.

## Customization

To adapt this concept for a real café:

- Replace the illustrative menu and prices with approved business information.
- Add verified address, opening hours, and contact details.
- Replace sample imagery with appropriately licensed brand photography.
- Add functional ordering, booking, or contact integrations if required.

The current repository is a static front-end concept; it does not include a backend, database, online ordering, or reservation system.
